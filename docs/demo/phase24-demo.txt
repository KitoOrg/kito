== 2. Claude Code's hooks: the model when a session starts, the session at each edit

$ kito lanes
lane/1   alice        active      base ckpt#1     0 ops   0 files  in claude-code (claude-opus-5)  prices in cents
lane/2   bob          active      base ckpt#1     0 ops   0 files  say what the shop sells

(a session of Claude Code starts on "claude-sonnet-5", then edits README.md in lane/2)

$ kito board
lane/1  alice (of ada) in claude-code (claude-opus-5)  active  prices in cents
  scope    src/shop.ts:total
lane/2  bob (of ada) in claude-code (claude-sonnet-5)  active  say what the shop sells
  scope    README.md

== 3. Another assistant takes lane/2 over

$ kito hook before-edit --file /demo/shop/.kito/lanes/2/work/README.md --assistant codex --model gpt-5-codex

$ kito --json lanes     (the part that says it)
"id":"lane/1"
"assistant":{"name":"claude-code","version":"2.1.0","model":"claude-opus-5"}
"id":"lane/2"
"assistant":{"name":"codex","model":"gpt-5-codex"}
