# 1. The server: a repository, its check, its git remote, three people

$ kito-server init /tmp/kito-demo/server
Kito server created in /tmp/kito-demo/server
Add a repository with `kito-server --dir /tmp/kito-demo/server repo add <name>`,
a person with `user add <name>`, then run `serve`.

$ kito-server --dir /tmp/kito-demo/server repo add shop --from /tmp/kito-demo/shop-src
Repository `shop` created in /tmp/kito-demo/server/repos/shop
Its main lane is protected: it changes only when a lane is integrated.

$ kito-server --dir /tmp/kito-demo/server repo set shop --check python3 tests/test_shop.py --push /tmp/kito-demo/upstream.git
shop  [main protected, checks: python3 tests/test_shop.py, pushes to /tmp/kito-demo/upstream.git]

$ kito-server --dir /tmp/kito-demo/server user add ada; … user add bob --role write; … user add carol --role read
(three tokens, each shown once)

$ kito-server --dir /tmp/kito-demo/server user list
ada: * (integrate)
bob: * (write)
carol: * (read)

(each connects a directory of their own: ada, bob, carol)
