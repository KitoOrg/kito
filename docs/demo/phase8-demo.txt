# 1. The server: one repository, two people

$ kito-server init /tmp/kito-demo/server
Kito server created in /tmp/kito-demo/server
Add a repository with `kito-server --dir /tmp/kito-demo/server repo add <name>`,
a person with `user add <name>`, then run `serve`.

$ kito-server --dir /tmp/kito-demo/server repo add shop --from /tmp/kito-demo/shop-src
Repository `shop` created in /tmp/kito-demo/server/repos/shop

$ kito-server --dir /tmp/kito-demo/server user add ada; … user add bob
(two tokens, each shown once)

$ kito-server --dir /tmp/kito-demo/server serve --listen 127.0.0.1:7421 &
kito-server: listening on 127.0.0.1:7421, 1 repositories


# 2. Ada, on her laptop: a lane on the server, its files on her machine

$ kito connect 127.0.0.1:7421 shop laptop --token kito_…
/tmp/kito-demo/laptop is connected to `shop` on 127.0.0.1:7421 as ada.
The main lane is in it (2 files), kept as the server has it: to change something, open a lane.
A lane you open is edited on this machine and recorded on the server;
`kito lane attach <lane>` brings the files of another's lane here, kept in step.
