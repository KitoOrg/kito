# 2. A client that is given another fingerprint does not connect

$ kito connect 127.0.0.1:33021 shop eve --token kito_<token> --fingerprint sha256:abababababababababababababababababababababababababababababababab
kito: cannot reach the server: 127.0.0.1:33021: the server presents a certificate with fingerprint
sha256:983a088d07244a9c4ae1357666412b973024b962fb40eab24ca3098736f636b3, not the one this directory
was connected with: either the server has a new certificate (ask whoever runs it, then connect
again with --fingerprint) or this is not the server

$ kito connect 127.0.0.1:33021 shop ada --token kito_<token> --fingerprint sha256:983a088d07244a9c4ae1357666412b973024b962fb40eab24ca3098736f636b3
/demo/ada is connected to `shop` on 127.0.0.1:33021 as ada.
The connection is encrypted, and the server is known by its certificate
(sha256:983a088d07244a9c4ae1357666412b973024b962fb40eab24ca3098736f636b3): one that presents
another is refused.
