# 3. A session starts: what the agent knows before its first word

$ kito hook session-start
  [told to the model]
  Kito keeps the history of this repository, and holds every agent to three rules. They are
  enforced, not advice:
  - Work in a lane. The open_lane tool opens one and gives its working copy; an edit in the
  main directory is refused.
  - Change what the lane declared. An edit outside its scope is refused until the extend_scope
  tool declares it.
  - Know why code is the way it is before you change it. Declaring something tells you its
  reasons; an edit on lines written for a reason you were not told is held back once, with the
  reasons, and goes through when made again.
  No lane is open right now.


# 4. An edit in the main directory is not made

(agent) Edit src/shop.py:      cut = amount * percent // 100  ->      cut = percent
  [NOT MADE]
  Kito: src/shop.py is in the main directory, and agents do not edit there (it is where
  finished work lands, not where it is made). Open a lane with the open_lane tool, saying what
  you will change and why (in a lane you already have, declare this file with extend_scope
  instead); the answer gives the working copy (`workdir`) and tells why the code you declared is
  the way it is. Then make this edit there: <workdir>/src/shop.py.

# 6. An edit outside what the lane declared is not made; declared, it is

(agent) Edit .kito/lanes/3/work/src/shop.py:          result += round(price * 100)  ->          result += int(price * 100)
  [NOT MADE]
  Kito: src/shop.py:total is outside what lane/3 declared (src/shop.py:discount), so this edit
  was not made. Declare it first: call the extend_scope tool with lane "lane/3" and scope
  ["src/shop.py:total"]. Its answer tells why that code is the way it is and who else is on it.
  Then make this edit again.
